## 唔只係統一畫面

- 呢份手冊連結基礎元素、設計原則、核心模組、完整工作流程、案例、動效及 AI Agent 使用方式。先了解用戶要完成嘅事，再揀版面、內容及元件。
- Kenny Lim 係呢份 Design System 嘅 founder；Founder’s Note 將產品判斷整理成可理解、可沿用、可持續演進嘅設計方向。

## 兩種閱讀模式

- 精簡模式先睇示例與主要規則；詳細模式展開規則及来源。兩個模式用同一套內容，唔會刪走費用、風險或不可還原後果。
- 搜尋涵蓋所有章節、表格、案例與來源；⌘ / Ctrl K 開啟搜尋，方向鍵揀結果，Enter 跳入章節。

## 由規格到採用

- 示例、Design System 提案同 App 已有實作係三種唔同狀態。每次 rollout 要核對來源、權限、錯誤與真實資料。
- 今次只改手冊。舊章節、互動示例同既有 hash 繼續有效；版本、固定香港時間同 Git 記錄一齊保存。
