# Accessibility

Binding rules for shipped UI. WCAG 2.2 AA is the floor, not the ceiling.

## Color contrast

| Pair | Required | Status |
|------|----------|--------|
| `text.primary` on `bg.raised` | ≥ 7:1 (AAA) | ✅ 16.1:1 |
| `text.secondary` on `bg.raised` | ≥ 4.5:1 (AA) | ✅ 8.9:1 |
| `text.tertiary` on `bg.raised` | ≥ 4.5:1 (AA) | ✅ 4.6:1 |
| `text.primary` on `bg.canvas` | ≥ 7:1 | ✅ 16.5:1 |
| `state.critical` on `criticalBg` | ≥ 4.5:1 | ✅ 5.2:1 |
| `state.success` on `successBg` | ≥ 4.5:1 | ✅ 4.8:1 |

## Focus

- Every interactive element has a visible focus indicator (`--color-border-focus`, 2px outline + 2px offset).
- Focus order follows DOM order. Never override with `tabindex` ≥ 0 without justification.
- Skip-to-content link is the first focusable element on every page.

## Motion

- Honor `prefers-reduced-motion: reduce`. Replace non-essential motion with instant state changes.
- No auto-playing animation longer than 5s without user control.

## Keyboard

- Every action reachable by mouse is reachable by keyboard alone.
- Escape closes modals, popovers, menus. Enter submits forms. Arrow keys navigate menus and tab groups.

## Targets

- Touch targets ≥ 44×44px on mobile, ≥ 24×24px on desktop.
- Spacing between adjacent targets ≥ 8px.

## Semantics

- One `<h1>` per page. Heading levels never skip.
- `<button>` for actions, `<a>` for navigation. Never the reverse.
- Form fields always have a `<label>` (or `aria-label` / `aria-labelledby`).
